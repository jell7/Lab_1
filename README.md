# Lab 01 — The Event Loop Is the Game Loop

## Опис проєкту
Ігровий рушій космічного корабля на Vite та Vanilla JS, реалізований за допомогою ігрового циклу з фіксованим кроком (Fix Your Timestep), інтерполяції рендерингу та управління через замикання.


## Результати експериментів (M4)

### 1. Блокуючий цикл у кадрі (Busy-wait)
* **Що зроблено:** У цикл рендерингу або симуляції було додано синхронне зависання: `const t = performance.now(); while (performance.now() - t < 100) {}` кожні 60 кадрів.
* **Що побачив гравець:** Гра починає сильно «фризити» і смикатися кожну секунду, інтерфейс і анімації завмирають.
* **Показники HUD:** Лічильник `Frames/s (Graf)` падає у кілька разів під час фризу, а `Frame Time` стрибає вище 100 мс.
* **Пояснення через Event Loop:** Оскільки JavaScript виконується в **один потоці** (single-threaded), будь-який важкий синхронний цикл повністю блокує Call Stack. Доки стек не звільниться, Event Loop не може взяти з черги жодної іншої задачі чи виконати рендеринг кадру (paint). JavaScript фізично не може «обійти» це з того ж потоку.

### 2. Заміна `requestAnimationFrame` на `setInterval(frame, 16)`
* **Що зроблено:** `requestAnimationFrame` було замінено на таймер `setInterval` із інтервалом 16 мс.
* **Що побачив гравець / показники:** Лічильник `Frames/s` втрачає синхронізацію з частотою монітора (пливе), з'являються мікроринвки (jank), оскільки 16 мс не дорівнює точним герцам екрана (наприклад, 16.67 мс для 60 Гц або 8.33 мс для 120 Гц). При згортанні вкладки браузера `setInterval` продовжує працювати на фоні, споживаючи ресурси, тоді як `requestAnimationFrame` автоматично стає на паузу.

### 3. Змінний крок замість фіксованого (Variable Timestep)
* **Що зроблено:** З симуляції було прибрано накопичувач (`accumulator`), і рух корабля став розраховуватися одразу на основі реального дельта-часу кадру (`simulate(dt)`).
* **Що сталося:** У браузері (або через обмеження CPU в DevTools у 6-кратному режимі сповільнення) траєкторія та швидкість польоту корабля почали суттєво відрізнятися порівняно зі звичайним запуском. При різких лагах корабель «телепортується» або проходить крізь стіни/межі.
* **Висновок:** Фіксований крок (`1/60` с) робить симуляцію детермінованою та незалежною від потужності заліза гравця, що є критично важливим для ігор.
